# Управление кешем отправленных файлов

## Описание

Реализована функциональность отслеживания отправленных файлов в кеше. Теперь файлы, которые уже были отправлены в чаты, помечаются как отправленные и исключаются из последующих выборок, что предотвращает повторную отправку одних и тех же фотографий.

## Как это работает

### Глобальный кеш

Добавлено новое поле `sent_files` в глобальный кеш `_folder_scan_cache`:

```python
_folder_scan_cache = {
    'all_files': [],           # Все найденные медиа файлы
    'scan_time': 0,            # Время последнего сканирования
    'cache_expires': 0,        # Время истечения кеша (случайное от 1 до 5 дней)
    'folders_scanned': 0,      # Количество отсканированных папок
    'sent_files': set()        # Множество путей отправленных файлов
}
```

### Основные функции

#### `mark_file_as_sent(file_path)`
Помечает файл как отправленный, добавляя его путь в множество `sent_files`.

```python
mark_file_as_sent("/path/to/photo.jpg")
```

#### `remove_file_from_cache(file_obj)`
Удаляет файл из кеша и помечает его как отправленный.

#### `get_cache_stats()`
Возвращает статистику о кеше для отладки:
- `total_files` - общее количество файлов в кеше
- `sent_files` - количество отправленных файлов
- `available_files` - количество доступных для отправки файлов
- `folders_scanned` - количество отсканированных папок

#### `clear_photo_cache()`
Обновлена для очистки списка отправленных файлов при полной очистке кеша.

### Интеграция в бота

#### В функции `send_welcome()`:
После успешной отправки фото пользователю файл автоматически помечается как отправленный:

```python
# После успешной отправки
mark_file_as_sent(photo.path)
```

#### В функции `scheduled_photo_sender()`:
После успешной автоматической отправки фото по расписанию файл также помечается как отправленный:

```python
if success:
    print(f"Успешно отправлено в чат {chat_id}")
    mark_file_as_sent(photo.path)
```

#### В функции `find_available_photos()`:
Функция автоматически фильтрует отправленные файлы перед возвратом результата:

```python
# Фильтруем отправленные файлы
sent_files = _folder_scan_cache['sent_files']
unsent_files = [f for f in all_files if f.path not in sent_files]
```

## Поведение

1. **Первая отправка**: Файл выбирается из кеша и отправляется пользователю
2. **Пометка**: После успешной отправки файл помечается как отправленный
3. **Последующие запросы**: Помеченные файлы исключаются из выборки
4. **Сброс**: При очистке кеша (через `clear_photo_cache()`) или истечении времени жизни кеша список отправленных файлов очищается, и файлы снова становятся доступными

## Преимущества

- **Избегание повторов**: Предотвращает отправку одних и тех же фотографий в течение жизни кеша (1-5 дней)
- **Эффективность**: Использует множество (set) для быстрой проверки отправленных файлов (O(1))
- **Гибкость**: Можно легко очистить список отправленных файлов при необходимости
- **Статистика**: Функция `get_cache_stats()` позволяет отслеживать состояние кеша

## Примечания

- Список отправленных файлов хранится только в памяти и сбрасывается при перезапуске бота
- Время жизни кеша составляет случайное значение от 1 до 5 дней
- При истечении кеша список отправленных файлов также очищается
