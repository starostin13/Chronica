# Реализация отслеживания отправленных файлов в кеше

## Краткое описание

Реализована функциональность для отслеживания файлов, которые уже были отправлены в чаты. Это предотвращает повторную отправку одних и тех же фотографий в течение срока действия кеша (1-5 дней).

## Как работает решение

### Алгоритм:

1. **Сканирование:** При запросе фотографий система сканирует Яндекс.Диск и кеширует все медиа файлы
2. **Фильтрация:** При выборке файлов система исключает те, что находятся в `sent_files`
3. **Отправка:** При успешной отправке путь файла добавляется в `sent_files`
4. **Исключение:** При следующих запросах этот файл уже не будет выбран
5. **Сброс:** При истечении кеша или его очистке список `sent_files` также очищается

### Диаграмма процесса:

```
find_available_photos()
    ↓
Проверка актуальности кеша
    ↓
Загрузка файлов (если кеш устарел) или использование кеша
    ↓
Фильтрация: [f for f in all_files if f.path not in sent_files]
    ↓
Фильтрация по дате (если search_by_date=True)
    ↓
Возврат списка доступных файлов
    ↓
[Отправка файла в чат]
    ↓
mark_file_as_sent(photo.path)
    ↓
Файл добавлен в sent_files
```

## Преимущества решения

1. **Минимальные изменения:** Добавлены только необходимые функции без изменения существующей архитектуры
2. **Эффективность:** Используется `set()` для быстрой проверки наличия файла (O(1))
3. **Безопасность:** Не нарушает работу планировщика и существующую логику
4. **Гибкость:** Легко отключить или изменить поведение
5. **Тестируемость:** Покрыто юнит-тестами
6. **Документированность:** Добавлена подробная документация

## Поведение в граничных случаях

1. **Все файлы отправлены:** Функция вернет пустой список и выведет сообщение "⚠️ Все файлы были отправлены"
2. **Перезапуск бота:** Список отправленных файлов сбрасывается (хранится только в памяти)
3. **Истечение кеша:** При истечении кеша список отправленных файлов автоматически очищается
4. **Ручная очистка:** Можно очистить кеш и список отправленных файлов через `clear_photo_cache()`

## Пример использования

### Получение статистики кеша:

```python
from yaHelper import get_cache_stats

stats = get_cache_stats()
print(f"Всего файлов: {stats['total_files']}")
print(f"Отправлено: {stats['sent_files']}")
print(f"Доступно: {stats['available_files']}")
```

### Ручная пометка файла:

```python
from yaHelper import mark_file_as_sent

mark_file_as_sent("/disk/Photos/2023/photo.jpg")
```

### Очистка кеша:

```python
from yaHelper import clear_photo_cache

clear_photo_cache()  # Очистит и sent_files
```
