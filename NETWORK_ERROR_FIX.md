# Решение проблемы с ошибками подключения (port 443)

## Проблема

Бот испытывал частые сетевые ошибки, **в основном при polling Telegram API**:
- `HTTPSConnectionPool(host='api.telegram.org', port=443): Max retries exceeded`
- `ProxyError: Unable to connect to proxy`
- `Service Unavailable (503)`
- `Remote end closed connection without response`

Бот постоянно перезапускался каждые 15 секунд, создавая лишнюю нагрузку на сеть.

Дополнительно возникали ошибки при работе с Яндекс.Диском:
- `Unknown Yandex.Disk error` - при скачивании файлов

## Решение

Реализована стратегия **экспоненциальной задержки (exponential backoff)** с увеличенным количеством попыток.

### Ключевые улучшения:

#### 1. Улучшенный основной цикл бота - ГЛАВНОЕ ИСПРАВЛЕНИЕ (bot.py)

**Это основное изменение**, которое решает проблему постоянных ошибок polling Telegram API.
- **Экспоненциальная задержка**: 15, 30, 60, 120, 240, 300 секунд
- **Максимальная задержка**: 5 минут (предотвращает бесконечное ожидание)
- **Сброс счетчика**: при успешном подключении
- **Отслеживание попыток**: для диагностики

**Было:**
```
Ошибка → ждём 15 секунд → снова пытаемся
Ошибка → ждём 15 секунд → снова пытаемся
...постоянно 15 секунд...
```

**Стало:**
```
Ошибка 1 → ждём 15 секунд
Ошибка 2 → ждём 30 секунд
Ошибка 3 → ждём 60 секунд
Ошибка 4 → ждём 120 секунд (2 минуты)
Ошибка 5 → ждём 240 секунд (4 минуты)
Ошибка 6+ → ждём 300 секунд (5 минут, максимум)
```

### Преимущества экспоненциальной задержки:

1. **Снижает нагрузку на сеть**: не перегружаем сервер частыми запросами
2. **Адаптируется к проблемам**: даёт больше времени для восстановления при серьёзных сбоях
3. **Быстрое восстановление**: короткая первая задержка для временных сбоев
4. **Предотвращает DOS**: не создаём дополнительной нагрузки при проблемах с сервером

#### 2. Дополнительно: улучшения для Яндекс.Диска (yaHelper.py)

Также улучшена обработка ошибок при скачивании файлов с Яндекс.Диска:

- **Конфигурация YaDisk**: `timeout=30.0`, `max_retries=5`
- **downloadFile()**: 5 попыток вместо 3, экспоненциальная задержка (4-64 сек)
- **Сканирование папок**: повторные попытки на каждом уровне

## Тестирование

- ✅ Проверка количества попыток (5 для downloadFile)
- ✅ Проверка конфигурации таймаутов (30 секунд)
- ✅ Проверка ограничения максимальной задержки (300 секунд)

Все тесты пройдены успешно.

## Ожидаемый результат

После внедрения этих изменений:
1. **Меньше ошибок**: увеличенное количество попыток и таймаутов
2. **Автоматическое восстановление**: при временных проблемах с сетью
3. **Лучшая диагностика**: информативные логи с номерами попыток
4. **Стабильная работа**: даже при нестабильном интернет-соединении

## Рекомендации

Если ошибки продолжают появляться часто:
1. Проверьте качество интернет-соединения
2. Проверьте настройки прокси (если используется)
3. Убедитесь, что токены Яндекс.Диска и Telegram актуальны
4. Рассмотрите возможность увеличения таймаута до 60 секунд в `yaHelper.py`

## Мониторинг

Следите за логами бота. Теперь вы увидите:
- 📸 Запуск операций
- ⏳ Ожидание между попытками
- ✅ Успешные операции
- ❌ Ошибки с номерами попыток
- 💾 Информацию о кеше

Это поможет лучше понимать, когда и почему возникают проблемы.
