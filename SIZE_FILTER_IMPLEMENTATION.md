# Реализация фильтра по размеру файла

## Описание проблемы

Иногда Telegram отклоняет отправку файлов с сообщением "Изображение слишком большое". Необходимо было реализовать механизм запоминания максимального размера файла и фильтрации файлов при выборе.

## Реализованное решение

### 1. Структура кеша (yaHelper.py)

Добавлено новое поле в глобальный кеш:
```python
_folder_scan_cache = {
    "all_files": [],
    "scan_time": 0,
    "cache_expires": 0,
    "folders_scanned": 0,
    "max_file_size": None,  # Новое поле для хранения максимального размера
}
```

### 2. Новые функции в yaHelper.py

#### `set_max_file_size(file_size_bytes)`
- Сохраняет размер файла, который не удалось отправить
- Обновляет максимум только если новый размер меньше текущего
- Вызывается из bot.py когда Telegram отклоняет файл

#### `get_max_file_size()`
- Возвращает текущий максимальный размер файла
- Возвращает `None` если ограничения нет

### 3. Фильтрация в find_available_photos()

Добавлена фильтрация файлов по размеру перед возвратом результата:
```python
max_size = _folder_scan_cache["max_file_size"]
if max_size is not None:
    all_files = [
        f for f in all_files
        if hasattr(f, "size") and f.size is not None and f.size <= max_size
    ]
```

### 4. Интеграция с bot.py

Обновлены функции отправки для сохранения размера при ошибке:
- `try_send_small_image()` - строка 354-355
- `try_send_video()` - строка 395-396

При ошибке отправки:
```python
if hasattr(photo, "size") and photo.size:
    set_max_file_size(photo.size)
```

### 5. Обновление clear_photo_cache()

Функция теперь также сбрасывает `max_file_size` в `None` при очистке кеша.

## Источник данных о размере

Размер файла получается из API Яндекс.Диска через атрибут `photo.size` (в байтах). Это происходит при сканировании папок, поэтому нет необходимости дополнительно скачивать файлы для определения размера.

Созданы два набора тестов:

Модульные тесты:

- `test_filter_files_without_size()` - обработка файлов без атрибута size
- `test_no_filter_when_max_is_none()` - работа без ограничений

### tests/test_integration_size_filter.py
Интеграционный тест, имитирующий реальный сценарий работы бота:
1. Начальное состояние без ограничений
2. Telegram отклоняет файл 8 MB
3. Система устанавливает максимум и фильтрует файлы
4. Telegram отклоняет файл 3 MB
5. Максимум уменьшается
6. Попытка увеличить максимум игнорируется

## Логирование

Добавлены информативные сообщения в консоль:
- При установке максимума: `📏 Установлен максимальный размер файла: X.XX MB`
- При фильтрации: `📏 Отфильтровано N файлов превышающих максимальный размер X.XX MB`

## Поведение системы

1. **При старте**: максимальный размер не установлен (`None`), все файлы доступны
2. **При ошибке отправки**: размер файла сохраняется как максимум
3. **При выборе файлов**: автоматически исключаются файлы больше максимума
4. **При очистке кеша**: максимальный размер сбрасывается
